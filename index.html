Stack & strumenti

Quello che uso davvero, quotidianamente. Niente tecnologie da vetrina.

  • ⚛

    React & JavaScript

    JavaScript ES6+, componenti, hook e gestione dello stato. HTML5 e CSS3 scritti bene, anche quando il framework li nasconde.

  • Φ

    Laravel & PHP

    Architettura MVC, Eloquent, code queue e API REST. Il backend è il pezzo che preferisco: si progetta, non si improvvisa.

  • ◉

    MySQL

    Schema relazionale, query ottimizzate, indici e migrazioni pulite. Il modello dei dati viene prima dell'interfaccia.

  • ◈

    Livewire

    Interattività senza JS pesante: hook e componenti server-side. Il modo più rapido per costruire gestionali che reggono.

  • ◇

    Tailwind CSS

    Utility-first, design system coerente, temi chiaro e scuro senza CSS duplicato. Il layout è una funzione dei dati.

  • ⌥

    Git & tooling

    Git e GitHub, Composer, npm, Vite, PHPUnit. Tieni l'ambiente riproducibile: se non si reinstalla, non è finito.
